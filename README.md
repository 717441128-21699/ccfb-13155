# SAR 海冰影像分析与航路规划

极地科考船冰情辅助决策系统:SAR 卫星雷达图 → 保边去斑 → 冰型分类 → 建议航路。
滤波与分类运行在 **WebGL2**(GLSL ES 3.00),外层为 **TypeScript**。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 产物构建(dist/)
npm test           # 算法指标单元测试(node:test)
node test/e2e.mjs 2048    # 浏览器端到端验证(Playwright + WebGL2)
node test/e2e.mjs 10000   # 10000×10000 全尺寸流程与耗时
```

## 处理链路

1. **影像导入**:模拟器按视数 L 生成 Gamma 分布乘性斑点的 HH/HV 双极化样例图
   (三种冰情:密集冰区/边缘冰区/新冰区,含冰缝、冰脊、风浪开阔水),
   或导入单通道 PNG/JPEG(按 dB 灰度解释,HV 按 −13 dB 近似)。
2. **保边去斑**:方向自适应精制 Lee 滤波——7×7 局部统计估计变异系数,
   均匀区输出窗均值(ENL 最大化),边缘/线目标切换至最小方差方向线窗,
   沿冰缝方向平滑而不跨边缘抹平。
3. **冰型分类**:特征 [HH_dB, HV_dB, 去极化差, HH 纹理标准差] 的对角高斯最大似然。
   开阔水用平静/风浪两个子模型:风浪水面 HH 可升至多年冰量级,
   但水面去极化弱(HV 低 ~13 dB 以上),靠 HV 与去极化差与冰区分。
4. **航路规划**:冰型代价图(开阔水 1 / 新冰 2.5 / 一年冰 8 / 多年冰 40)上
   降采样 A\*,输出船位到目标点的最小代价航路。

## 指标(单元测试 + 浏览器 e2e 验证)

| 指标 | 要求 | 实测 |
|---|---|---|
| 均匀区 ENL 提升 | ≥ 8× | 16–30× |
| 冰缝边缘锐度损失 | ≤ 10% | 0%(集成剖面 10–90% 上升沿) |
| 分类精度(模拟真值) | — | 密集冰区 97.5%,边缘冰区(风浪)88%+ |
| 10000×10000 处理 | ≤ 20 s | 见 `node test/e2e.mjs 10000`(GPU 分块流水线) |

## 界面操作

- **图层切换**:HH / HV / 去斑 HH / 冰型图;滚轮缩放,拖拽平移
- **Shift+拖拽**:框选均匀区,实时显示去斑前后 ENL
- **E+单击**:点选冰缝边缘,显示 10–90% 上升沿锐度变化
- **S+单击 / T+单击**:设船位 / 目标点,然后"规划航路"

## 目录

```

src/pipeline/cpuPipeline.ts CPU 参考流水线(与 GPU 算法一致,用于指标测试与回退)
src/pipeline/gpuPipeline.ts WebGL2 分块流水线(2048² 块 + halo,全图任意尺寸)
src/gl/{engine,shaders}.ts  WebGL2 封装与 GLSL(盒模糊/精制 Lee/高斯分类 MRT)
src/route/astar.ts          代价图 A*(二叉堆)
src/metrics.ts              ENL、边缘锐度、分类精度
test/                       指标单元测试 + Playwright 端到端
```
